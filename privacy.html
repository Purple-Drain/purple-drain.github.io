Privacy policy: patreon-kodi-pipeline

Last updated: 06.11.26

What the app is

patreon-kodi-pipeline is a private set of scripts run by one person on their own machine. It adds videos to playlists in that person's own YouTube account. It is not offered to other users.

YouTube data it uses

The app uses the YouTube Data API to read and change playlists on the account that authorised it. It does not read messages, contacts, or any other account data.

What is stored

A Google OAuth token is kept on the operator's own server, with restricted file permissions. The token is used only to call the YouTube API for that account. It is never shared or sent to any third party.

What is not collected

The app has no analytics, advertising, tracking, or user accounts of its own. It does not send YouTube data anywhere except back to YouTube.

Revoking access

You can remove the app's access at any time from your Google Account under Security, then Third-party access.

Contact

Questions about this policy can be raised as an issue on the project's GitHub page.
